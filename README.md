# Touchline

A free Master League companion for SP Football Life 2026. It runs in its own
window beside the game, reads your career save and builds the world around it.

**[Download the latest release](https://github.com/ahmadsk-cell/Touchline/releases/latest)** ·
[Install guide](https://askandalus.com/downloads/touchline/install-guide.html) ·
[askandalus.com/downloads/touchline](https://askandalus.com/downloads/touchline)

This repository holds Touchline's releases. Download the `Touchline-<version>.zip`
asset from a release, not the "Source code" archives GitHub adds automatically.

## What it does

- Stories, player messages and press questions that arrive as your career moves on
- Players with opinions, a board with a memory, and staff you hire and manage
- Sponsors, player bonuses and staff wages settled against your real transfer and
  salary budgets, with one switch to turn it off
- Form arcs and long-term coaching that make small, earned changes in the running game
- Reads your save and never edits it; Football Life still writes it itself
- In English, Spanish, Portuguese, French and Italian (Settings > Presentation >
  Language). Stories and letters are in English for now.

## Before you install

- Football Life 2026. Live features need version 1.4; other versions still get
  everything built from your save.
- Sider, with the game started through it
- A Master League career saved at least once
- Windows 10 or 11

## Install

1. Download `Touchline-<version>.zip` from the
   [latest release](https://github.com/ahmadsk-cell/Touchline/releases/latest).
2. Extract it completely. Do not run anything from inside the zip.
3. Run `TouchlineSetup.exe` and follow the
   [install guide](https://askandalus.com/downloads/touchline/install-guide.html).

Setup adds a TouchlineCompanion folder and three small Sider scripts, backs up
`sider.ini` before switching those scripts on, and switches off `BudgetSetter.lua`
if you have it, since the two conflict. It never deletes anything and never
overwrites your own files.

## If Windows warns you

Touchline is not code-signed, so Windows may say it "protected your PC." Choose
**More info**, then **Run anyway**, or first check the zip against the
`SHA256SUMS.txt` published with each release.
